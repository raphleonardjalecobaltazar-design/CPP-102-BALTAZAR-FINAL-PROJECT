## Project Description
This program monitors the student grades. It classifies each reading as EXCELLENT, PASSED or FAILED and prints a summary with the overall remarks
 
## Features
- View all stored student grades
- Add a new reading (whole numbers from 0 to 100 only)
- Classifies every reading
- Generate a numerical summary and overall remarks
- Rejects an invalid menu choices and invalid readings
 
## Requirements
- Python 3 (no external packages)
 
## How to Run
1. Open a terminal inside the Week17 folder.
2. Type: python student_grade_monitoring_system.py
   (On macOS or Linux, type: python3 student_grade_monitoring_system.py)
